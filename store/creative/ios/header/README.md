# App Store product page header image (IOS_UPLOAD_CREATIVE_ASSETS)

Put one PNG of exactly 3840×1646 here, with no alpha channel. A new image is
uploaded to the App Store Connect Asset Library and reviewed on its own; once
Apple approves it, a release run places it on the version's en-US product page.
To change it, commit the new image under a new file name. Without an image this
slot is left alone. See [store/README.md](../../../README.md#header-and-search-results-images-ios).
